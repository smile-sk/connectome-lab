# ConnectomeLab

Отдельный исследовательский проект: **реальные коннектомы как источник архитектурных решений для агентных харнессов.**

Идёт **параллельно** с ai_ui и AIUI-BUS. Ничего в рабочем харнессе и на шине не перекраивается:
шина работает - её не трогаем, у Антона лимиты, ломать рабочее ради эксперимента нельзя.
Здесь - песочница. Если что-то отсюда окажется полезным, переносим в ai_ui отдельной задачей,
со снапшотом и живым прогоном.

## Зачем

Дрозофила (FlyWire / Codex, 2026) показала, что мозг - не монолитная сеть, а децентрализованная
система: локальные цепи, разреженная память, жёсткое торможение лишних сигналов, разделение
быстрого рефлекса и медленного планирования. Гипотеза проекта: **часть этих принципов переносится
в архитектуру агента не как метафора, а как числа** - из конкретного графа, с проверкой.

Первый объект - **C. elegans** (нематода), а не муха. Причина: у червя 302 нейрона, полный коннектом
с 1986 года, каждый нейрон поимённо описан (класс, медиатор, координаты) и - главное - у него
в данных есть **тело**: сенсор → интернейрон → мотонейрон → мышца замкнуты целиком. У мухи тела нет.

Второй объект - муха, вторая очередь (140k нейронов, поведение не подписано).

## E2 - привыкание и торможение контекста (2026-09-20, СДЕЛАНО)

Пакет `clab/` - примитивы, снятые с коннектома, без внешних зависимостей (только stdlib).
Прогон: `python scripts/e2_habituation.py` → отчёт `out/e2_report.md`. Время инжектируется
(`Clock`), поэтому числа воспроизводимы от прогона к прогону.

| Сценарий | Замер |
|---|---|
| S1 привыкание к повтору | 150 касаний (интервал 30 с) → в мозг прошло **3** (2%); на 60-м иной стимул → dishabituation, снова слышно (response 0.44); после паузы 20 мин - восстановление до 0.611 |
| S2 почтовик, 240 событий | тупой хеш-дедуп пропустил **74** (из них 51 - уникальные, но бессмысленные варианты info); привыкание tau_rec=120 с - **69**, info 175 → **4** (в 44 раза), ошибок поймано **23 из 23** при любом tau_rec |
| S2b кривая настройки | tau_rec 60/120/600 с → прошло 83 / 69 / 36 событий, ошибок 23/23 всегда |
| S3 шина | heartbeat `miriad/alive` ×30 → дошло **2**; адресные сообщения - **3 из 3**; первый сигнал нового агента - дошёл |
| S4 flapping (учащающийся warn) | 20 повторов по 2 с → прошло **7**, дальше тишина; после паузы 30 мин - снова слышно (0.704) |
| S5 разреженная проекция | код **20 индексов из 2000**; тот же текст - пересечение 1.000, тот же смысл с другим числом - 1.000, разное - 0.026; чужая фраза → `unknown` (0.026) |
| S6 context gate | 60 строк вывода инструмента → **10 строк**, 1502 → 429 символов, экономия **71.4%**; сохранены шапка, новые ошибки и **эскалации** (`повторов 39, эскалаций 3`); буквально одинаковые строки схлопываются |
| S7 вектор состояния | состояние = **44 токена** одной строкой вместо пересказа истории |

Три ошибки, которые я нашла и исправила В ПРОЦЕССЕ (это и есть ценность замеров):
1. dishabituation «на каждый error» - 42 warn из 42 прошли насквозь, поток не успокаивался.
2. То же «не чаще cooldown 120 с» - тоже мимо: ошибки шли реже 120 с, и каждая расшевеливала всё заново (91 из 240 на выходе).
3. Работает только НОВИЗНА: сбрасывает первый в жизни такой стимул, его повторы - нет.

Границы (честно, без романтики):
- **Редкий повтор не гасится.** Интервал больше tau_rec → восстановление проходит, событие проходит каждый раз. Привыкание фильтрует бёрсты, а не архивирует по факту.
- **Ошибка не гасится никогда** (floor 0.50 при пороге 0.35) - сознательная асимметрия.
- Числа (tau_rec, порог, k, floor) - подбор под конкретный поток, а не константа природы.
- Числа: в `sparse` токенизатор по-прежнему выбрасывает чистые числа («ошибка с другим числом» → тот же код). В `gate` это исправлено 20.09 по находке Ореста №2: для error/warn числа остаются в подписи, поэтому эскалация (таймаут вырос, упал другой порт) видна.
- За поведение это не отвечает: фильтр событий не заменяет ни планировщик, ни память.

Универсальность (то, ради чего пакет, а не скрипт): `clab` не знает ни про шину, ни про почтовик.

```python
from clab import make_filter
flt = make_filter("bus")        # или "mailbox", "toollog"
v = flt.feed({"from": "miriad", "topic": "heartbeat", "text": "alive"})
if v.emit:
    ...                          # только то, что достойно внимания
```

Новый поток подключается ОДНОЙ функцией `key_fn(ev) -> (key, kind, text)` в `clab/adapters.py`
(три готовых маппера: шина, почтовик, логи инструментов). Остальные модули не меняются.

## E3 - динамика по коннектому (2026-09-20, СДЕЛАНО)

`python scripts/e3_dynamics.py` → `out/e3_report.md`. Считает `clab/dynamics.py` - сеть
по РЕАЛЬНОМУ графу (4681 химическая связь + 1359 gap), numpy ускоряет, но не обязателен.

Модель - ставки (rate), а не спайки, и это биология: нейроны C. elegans работают
градиентными потенциалами. Первый заход был LIF и дал честный нуль - импульс от ASH до AVA
не доходил (одна связь из 87 входов AVAL = 1/660 веса). Записано в отчёте, не спрятано.

Числа (рабочий режим: нормировка `sum`, gain 0.5, знаки по медиатору):

- **Рефлекс сработал.** Касание ASH → AVA 0.208 → мотонейроны назад 0.0047 против вперёд
  0.0001 - **44×** в пользу отползания, как у биологов (ASH → AVAL/AVAR → DA/VA).
- **Направление несёт топология, не веса:** на бинарных весах (все связи = 1) знак ответа тот же.
- **Узкое горло подтверждено динамикой:** убить AVAL/AVAR → от рефлекса остаётся **0.5%**
  (0.00002 против 0.00472). Это динамическая версия того, что E1 видел по весам входа.
- **Привыкание вырастает из усталости синапса** и подчиняется закону пауза/τ_rec, как модуль E2:
  1 с паузы → 66% ответа, 3 с → 84%, 20 с → 99%; переключение τ_rec 1/4/20 с → 99.6/92.6/67.7%.
- **Движок сверен:** numpy против чистого Python - расхождение ~1e-16 на 1200 шагах
  в тихом режиме (воспроизводимо), но 0.5 в режиме самоподдержки: измеренный
  положительный показатель Ляпунова, сеть усиливает возмущение.

Чего динамика НЕ смогла (упёрлось в данные, не в код):

- **Знаков синапсов в датасете нет.** С приором «Glu тормозит» сеть слабая, с «Glu возбуждает» -
  самоподдерживающаяся. Хуже: при стимуле AVB модель гонит НАЗАД (DA 0.0042 против DB 0.0013) -
  командную цепь «вперёд» приор знаков переворачивает. Рефлекс угадывается, произвольное
  движение - нет.
- **Весов нет** (только число контактов) → узкий динамический диапазон: либо еле слышно, либо генератор.
- **Dishabituation из сети не выходит.** Новый стимул даёт сильный ответ, но привычку не сбрасывает:
  нужны нейромодуляторы (серотонин/дофамин), которых в модели нет. Отсюда вывод: правило
  «сбрасывает только первый в жизни стимул» - наш инженерный аналог модуляции, и оно живёт
  в `clab/habituation.py` явно.
- Нормировка `sqrt` уводит сеть в самоподдержку (0.13-0.86 активности без входа) - не годная.

Следующий шаг по данным: предсказанные знаки синапсов / функциональные веса -
WormNeuroAtlas (Randi 2023), кальциевые записи WormWideWeb. Без них мы угадываем торможение.
Реальные 3D-координаты - WormWiring; в owmeta лежит только грубая категория (`1 .2 1`),
поэтому «тело из данных» (E5) опирать на owmeta нельзя.

## E6 - тела из СВОИХ данных (2026-09-20, СДЕЛАНО)

Не биология, а мы сами: `scripts/e6_own_graphs.py` собирает тела из того, чем проект живёт.
Формат и запись - `clab/graphbuild.py` (один код на все источники: коннектом, шина, память).

- **bus** - шина сигналов: узлы = агенты и собеседники, рёбра = сообщения (вес = сколько),
  импульс = РЕАЛЬНОЕ время сообщений (120 бинов по 4.4 ч, цикл 30 с), drive = перевес входящих
  над исходящими (тело тянется к тем, кто пишет). 30 сообщений, 4 ящика.
- **memory** - память агента: 444 записи `notes.md`, рёбра = общие редкие слова (>=2 значимых,
  вес = 10 x сумма idf), раскладка = спираль по времени (8 витков + детерминированное дрожание,
  иначе лента сливается в шнур: зазор узлов 0.049 -> 0.066 при радиусе узла ~0.028),
  импульс = хронология (кадр = одна запись, цикл 45 с). 991 связь.
- Вес рёбер памяти масштабирован x10 ОСОЗНАННО: читатель по умолчанию прячет рёбра с весом
  < edge_min (1.0) - без масштаба 7 связей исчезали молча, а структура терялась.

## E7 - тело МУХИ из реального коннектома (2026-09-20, СДЕЛАНО)

`scripts/e7_fly_graph.py` - Drosophila melanogaster (самка FAFB, релиз 783) БЕЗ Codex и логина:

- источник: Zenodo 18555170 (CC-BY-4.0), производные FlyWire: `coordinates.mat` (138 639 сом),
  `annotations.mat` (класс/подкласс/тип/суперкласс), `connectome.mat` (синапсы по медиаторам).
  Качает `scripts/e7_fetch_fly_data.py`, ~109 МБ. Данные: `data/fly/`.
- популяция задаётся аннотацией: по умолчанию `super_class=central` - центральный комплекс,
  **2317 нейронов, 5060 связей (>=3 синапсов), 44 734 синапса**.
- координаты РЕАЛЬНЫЕ (координаты сом, нм), медиатор нейрона - по ИСХОДЯЩИМ синапсам, палитра
  та же, что у червя. Знаки синапсов - из данных (ACh возбуждение, GABA торможение), не приор.
- **импульс** - прогон нашего движка E3 по этим же связям. КОНТРОЛЬ: без стимула сеть молчит
  (макс активации 0.000000), со стимулом срабатывает **18.7%** нейронов, средина срабатывания
  228 мс. Стимул выбран по данным: узел с сильнейшим ВХОДОМ извне популяции (2571 синапс).
- Сеть возбуждается целиком за единицы мс, поэтому показывается не реальное время, а ПОРЯДОК
  срабатывания (240 кадров, цикл 36 с): порядок настоящий, время растянуто - в `meta` сказано
  прямо. Второе касание не показывается: без гомеостаза сеть защёлкивается на плато (тот же
  вывод, что дал E4 у червя).

## Синхронизация двух копий гейта (2026-09-20)

Копии гейта (`clab/gate.py` - лаборатория, `ai_ui/app/agents/context_gate.py` - харнесс)
разъехались: в clab ключ привыкания считался по ОБЕЗЛИЧЕННОЙ подписи, в харнессе - по
точной (числа значимы). Уникальные данные с разными числами могли схлопнуться как
«повтор». Сделано:

1. **Ключ привыкания сведён:** обезличенная подпись применяется ТОЛЬКО к шуму
   (heartbeat/poll/retry), всё прочее - по точной подписи.
2. **Перенесён слой политики** (`apply_policy`, `gate_result`, `TEXT_KEYS`): решает,
   СТОИТ ли применять урезанный текст - экономия обязана быть ПОВТОРАМИ (≥40% строк),
   а не бюджетом. Уникальные данные уходят целиком.
3. **Сведены дефолты:** `numeric_kinds=("error", "warn", "info")` в обеих копиях.
   Числа значимы везде, кроме шума. Боевой харнесс передавал это явно, поэтому в бою
   данные не терялись - расходились именно дефолты.
4. **Закреплено тестами:** `tests/test_clab_regression.py` - 19 проверок (ключ, политика,
   эскалация, шум); `tests/test_parity_with_aiui.py` - 4 проверки паритета ОБЕИХ копий
   (дефолты, `signature`, `guess_kind` и поведение гейта на 8 сценариях, включая текст).
   Тест паритета опциональный: нет ai_ui на диске → SKIP (путь - в AIUI_PATH).

**Цена честности:** S6 в отчёте e2 - 1502 → 429 символов (71.4%) вместо прежних 421 (72.0%).
Восемь символов - это строки эскалации, которые теперь видно, а не «повтор».

```
  .venv/             отдельное окружение проекта (numpy и т.п.), ai_ui не трогаем
```

## Эксперименты (порядок и цена)

- **E1 - карта графа.** networkx: степени, хабы, разреженность, трассировка 5 известных цепей
  (escape, вперёд AVB/VB, поворот, хемотаксис, механосенсорика). Дёшево, статично, воспроизводимо.
- **E2 - привыкание (habituation).** СДЕЛАНО 2026-09-20: пакет `clab/` + `scripts/e2_habituation.py`,
  отчёт `out/e2_report.md` (вверху раздел с числами). Кандидат на перенос в харнесс.
- **E3 - динамика.** СДЕЛАНО 2026-09-20 своим движком (`clab/dynamics.py`, `out/e3_report.md`):
  рефлекс, узкое горло, привыкание, карта устойчивости. Открытый остаток - сверка с каноничной
  моделью `c302` (NeuroML/PyNN → NEURON/NEST/Brian2): ставится в `.venv` проекта, фоново.
- **E4 - НАСТОЯЩИЙ импульс для тела.** СДЕЛАНО 2026-09-20 (`scripts/e4_activity.py`,
  `out/e4_report.md`, `out/worm_activity.json`). Сеть прогоняется 11 с при касании носа ASH,
  покадровая активность (dt 50 мс) + моторная команда ложатся в формат `connectome-activity/1`
  рядом с телом, и в ai_ui тело светится ЭТИМИ числами (`app/scene/connectome.py`).
  Замер: на касании средняя яркость сом 0.86 против 0.29 в покое, ярких нитей 54% против 8%.
  ЧЕСТНЫЙ ВЫВОД: при усталости синапса depress 0.2/0.35 повторные касания дают РОВНО НОЛЬ
  даже через 8 с (tau_rec 8 с) - это защёлка, а не привыкание: у rate-модели нет гомеостаза.
  Поэтому импульс снят с depress=0 (ответы 100% / 51%), а у drive вычтен медленный дрейф фона.
  ОТКРЫТЫЙ ОСТАТОК E4: существо-ПРОЦЕСС, которое само читает сенсоры и пишет в протокол шины
  (шина не меняется - подключаемся снаружи). Пока сделан только «импульс для тела».
- **E5 - тело из данных.** СДЕЛАНО 2026-09-20: хук в воксельном рендерере
  `form='graph:<файл>' / 'points:<файл>'` (`ai_ui/app/scene/connectome.py`), плюс опции
  `?girth=3` (растянуть поперечные оси - нематода 15:1 иначе не читается) и `?edge_min=2`.
  Плотность точек на нити ∝ ДЛИНЕ связи, толщина ∝ весу, яркость ∝ активности.

- **E6 - тела из своих данных.** СДЕЛАНО 2026-09-20 (`scripts/e6_own_graphs.py`, `clab/graphbuild.py`,
  `out/e6_report.md`): шина сигналов и память агента как тела. Свои тела рядом, ai_ui не тронут.
- **E7 - тело мухи.** СДЕЛАНО 2026-09-20 (`scripts/e7_fly_graph.py`, `out/e7_report.md`): центральный
  комплекс 2317 нейронов из открытого дампа FlyWire v783 + настоящий импульс движком E3 с контролем.

## Правила проекта

- Ничего в `ai_ui` не правим из этого проекта без отдельной задачи и снапшота.
- Шина AIUI-BUS рассматривается как внешний интерфейс, только чтение, пока не скажет оператор.
- Каждый эксперимент = скрипт в `scripts/` + отчёт в `out/`, цифрами, а не словами.
- Правка по QA-отчёту закрывается регрессионным тестом в `tests/`, а не обещанием.
